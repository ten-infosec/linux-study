# P0-5. 가상머신 스냅샷 찍기와 되돌리기

- 날짜: 2026-09-29
- 환경: VirtualBox 7.2.10, 가상머신 `rocky9` (Rocky Linux 9.8 Minimal)

## 왜 하는가

- 방화벽, 디스크, 커널 설정처럼 시스템을 망가뜨릴 수 있는 실습 전에 **되돌릴 지점**을 만들어 두기 위해
- 망가져도 몇 초 만에 설치 직후 상태로 돌아갈 수 있다

## 스냅샷 찍기

- 가상머신을 `sudo poweroff`로 **끈 상태**에서 찍음 → 메모리 내용 없이 디스크 상태만 저장되어 작고 깔끔
- 찍기 전에 설치 ISO가 빠졌는지 확인 (설정 → 저장소 → IDE가 `비어 있음`)
- 이름: `01_clean-install`
- 설명: `Rocky 9.8 Minimal fresh install, user taeeun (wheel), no extra packages`

## 되돌리기 시험

```bash
touch snapshot-test.txt   # 스냅샷 이후에 파일 만들기
ls                        # snapshot-test.txt 보임
sudo poweroff
```

- VirtualBox 관리자 → 스냅샷 탭 → `01_clean-install` 줄 선택 → 복원
- "현재 가상 머신 상태 스냅샷 만들기" 체크 해제 → 지금 상태를 버리고 복원

```bash
ls                        # 아무것도 안 나옴 → 파일이 사라짐
```

## 확인

- 복원 후 `snapshot-test.txt`가 사라졌다 → 스냅샷 시점으로 정확히 돌아감

## 알게 된 점

- 스냅샷은 디스크 전체를 복사하지 않고, 이후 **바뀐 부분만 따로 기록**한다 → 찍는 데 몇 초
- 동적 할당 디스크: Virtual size 30 GB, Actual size 2.51 GB (쓴 만큼만 차지)
- 복원 시 "현재 상태 스냅샷 만들기"를 체크하면 지금 상태도 남길 수 있다. 중요한 작업 후에는 체크하는 게 안전

## 막혔던 점

- 복원 버튼이 회색 → `현재 상태`가 아니라 **스냅샷 줄을 선택**해야 활성화된다
- 복원 확인 창의 "현재 상태를 저장하지 않으면 복원할 수 없습니다"는 "지금 상태로 **다시 돌아올 수 없다**"는 뜻
